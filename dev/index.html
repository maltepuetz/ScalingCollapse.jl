What is ScalingCollapse.jl? ​

ScalingCollapse.jl automates finite-size scaling. Finite-size scaling determines the critical parameters of a phase transition, such as the critical temperature and the exponents and , from the way an observable changes with the system size . Given measurements for several sizes, the package finds the parameters for which all curves collapse onto a single master curve.

Development status

ScalingCollapse.jl is still in early development. Expect bugs and breaking changes, and feel free to open an issue if you run into a problem.
