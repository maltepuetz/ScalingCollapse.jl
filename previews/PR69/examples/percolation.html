Site percolation with error bars ​

Site percolation on the square lattice has a percolation threshold   (known numerically to high precision) and the exact exponents   and  . We analyze the order parameter, the relative size of the largest cluster, for   to , with error bars. The data are the example data of autoScale.py by O. Melchert (MIT license), shipped in test/testdata/autoscale of the repository.

This example shows how to use error bars, how corrections to scaling show up, and how the error methods differ.

The data ​

Every file has three columns: occupation probability , order parameter and its error. Lines starting with # are comments.

julia
using ScalingCollapse
using DelimitedFiles

dir = joinpath(pkgdir(ScalingCollapse), "test", "testdata", "autoscale")
Ls = [8, 16, 32, 64, 128, 256, 512]
tables = [readdlm(joinpath(dir, "orderParam_L$L.dat"); comments=true) for L in Ls]
ps = [t[:, 1] for t in tables]   # occupation probability
P = [t[:, 2] for t in tables]    # order parameter
Pe = [t[:, 3] for t in tables]   # its error

The sizes are measured at different values of and with different numbers of points, so all inputs are vectors of vectors. The error bars Pe are passed as the fourth argument.

julia
using CairoMakie

colors = cgrad(:Blues)[range(0.3, 1.0; length=length(Ls))]
fig = Figure(size=(620, 340))
ax = Axis(fig[1, 1]; xlabel=L"p", ylabel=L"P", title="order parameter")
for i in eachindex(Ls)
    errorbars!(ax, ps[i], P[i], Pe[i]; color=colors[i])
    scatterlines!(ax, ps[i], P[i]; color=colors[i], markersize=5, label="L = $(Ls[i])")
end
xlims!(ax, 0.45, 0.75)
Legend(fig[1, 2], ax)

Corrections to scaling ​

The scaling form only holds for large . A simple check is to drop the smallest sizes one after the other and watch whether the parameters drift:

julia
L_mins = Ls[1:5]
fits = [ScalingProblem(ps[k:end], P[k:end], Pe[k:end], Ls[k:end]; sf, p_space, dx)
        for k in eachindex(L_mins)]

exact = [0.5927460508, 4 / 3, 5 / 36]
labels = [L"p_c", L"\nu", L"\beta"]
fig = Figure(size=(780, 280))
for j in 1:3
    ax = Axis(fig[1, j]; xlabel=L"L_\mathrm{min}", ylabel=labels[j], xscale=log2,
        xticks=L_mins)
    hlines!(ax, [exact[j]]; color=:gray, linestyle=:dash)
    v = [f.optimal_ps[j] for f in fits]
    σ = [f.optimal_ps_error[j] for f in fits]
    errorbars!(ax, L_mins, v, σ; color=:black, whiskerwidth=6)
    scatter!(ax, L_mins, v; color=:black, markersize=8)
end
fig

Profile and bootstrap errors ​

With error bars, error=:bootstrap gives the statistical errors of the parameters: the spread of fits to data sets resampled within the error bars.

julia
using Random

for (name, s) in ("all sizes" => sp_all, "L ≥ 128" => sp)
    σ_boot = parameter_errors(s; method=:bootstrap, n_bootstrap=200, rng=Xoshiro(1))
    println(name)
    for j in 1:3
        p = ScalingCollapse.scaled_p_names(sf)[j]
        println("    ", rpad(p, 5), "deviation from exact ",
            rpad(round(s.optimal_ps[j] - exact[j]; sigdigits=2), 10),
            "profile ", rpad(round(s.optimal_ps_error[j]; sigdigits=2), 9),
            "bootstrap ", round(σ_boot[j]; sigdigits=2))
    end
end
all sizes
    p_c  deviation from exact -0.0011   profile 0.00063  bootstrap 1.7e-5
    nu   deviation from exact -0.035    profile 0.036    bootstrap 0.001
    beta deviation from exact 0.02      profile 0.0082   bootstrap 0.00021
L ≥ 128
    p_c  deviation from exact -0.00011  profile 7.9e-5   bootstrap 3.0e-5
    nu   deviation from exact -0.0062   profile 0.0072   bootstrap 0.0031
    beta deviation from exact 0.0017    profile 0.0013   bootstrap 0.00048

The bootstrap errors are several times smaller than the profile widths, and for all sizes the deviations from the exact values exceed them by more than an order of magnitude: the bootstrap measures the noise of the data, not the systematic error of an incomplete scaling form. Quote bootstrap errors only after checking for corrections to scaling as above. The profile widths are not calibrated either, but they are a more conservative measure of how well the data constrain the parameters.
